# CafeBot ☕

A beginner-friendly AI chatbot for cafe management and customer service.

## Project Structure
- `backend/`: Server-side logic and API integrations.
- `frontend/`: User interface code.
- `prompts/`: System prompts and AI persona definitions.
- `data/`: Mock data, menus, and knowledge base files.
- `env/`: Environment variable templates.

## Getting Started
1. Copy `env/.env.example` to `env/.env` and fill in your API keys.
2. Install dependencies (to be added).
3. Run the backend and frontend.
